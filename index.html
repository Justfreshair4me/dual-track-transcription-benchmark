Downloads, privacy, and offline limits

Only static model and runtime files are downloaded, from this site's host. The build retrieves pinned originals from Hugging Face's onnx-community repositories. No audio or text is uploaded. No speech service, analytics, account, database, service worker, or persistent model cache is used.

After a model has loaded, inference works without internet while this tab stays open. Loading a different model or reopening the site needs internet unless the browser happens to retain its ordinary HTTP cache. Keep this tab visible and the screen awake during tests.

CPU execution uses one thread in a separate worker. Memory use can be much larger than download size. Android can kill a tab without giving us a chance to recover it. Chrome and Brave support and speed still need physical-phone testing.
